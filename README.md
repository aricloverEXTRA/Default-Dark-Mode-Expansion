## ✨ About

Default Dark Mode: Expansion extends NebuIr's Default Dark Mode with dark-themed GUIs for **135+ mods** — from JEI, REI, Applied Energistics 2 and Create to Twilight Forest, Mekanism, Botania and more. Place this pack **above** Default Dark Mode in your resource pack list.

## 🧩 Mod Support

Full list of supported mods is on the [wiki](https://github.com/nebuIr/Default-Dark-Mode/wiki/Mod-support).

> Pack currently covers **135+ mods** in `assets/` (+ 1.21 overlay) — counted for `v2026.7.20` / `2026.9.1`.

## 📦 Installation

1. Install [Default Dark Mode](https://modrinth.com/resourcepack/default-dark-mode) by NebuIr.
2. Download **Default Dark Mode: Expansion** from Modrinth / CurseForge / Codeberg.
3. Place both packs in `resourcepacks/` and enable them — **Expansion on top**.
